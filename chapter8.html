1. Introduction to Strings

A string is a sequence of characters used to represent text. Examples include "Arman", "Kolkata", and "Hello World".

C does not have a separate built-in string data type. We usually store strings in arrays of characters. 

char name[] = "Arman";

The string is stored as individual characters followed by a special character called the null terminator: '\0'. 

'A'  'r'  'm'  'a'  'n'  '\0'
Remember: '\0' marks the end of a C string. It is not the same as the character '0'.

2. Declaration and Initialization

Method 1: Let C calculate the size

char name[] = "Arman";

C automatically reserves enough space for the characters and the null terminator.

Method 2: Specify the array size

char name[20] = "Arman";

This array has room for up to 19 ordinary characters plus the null terminator.

Method 3: Initialize characters individually

char name[] = {'A', 'r', 'm', 'a', 'n', '\0'};
A string array must have enough space for its characters and its terminating '\0'.

3. Taking String Input

Using scanf()

#include <stdio.h>

int main(void)
{
    char name[20];

    printf("Enter your name: ");
    scanf("%19s", name);

    printf("Hello, %s\n", name);

    return 0;
}

%s reads a word until whitespace, such as a space, is encountered. The width limit in %19s helps prevent writing beyond the 20-character array.

Using fgets()

#include <stdio.h>

int main(void)
{
    char name[50];

    printf("Enter your full name: ");

    if (fgets(name, sizeof(name), stdin) != NULL)
    {
        printf("Your name is: %s", name);
    }

    return 0;
}

Unlike scanf("%s", name), fgets() can read spaces. It may also keep the newline when the user presses Enter.

Example: If you enter MD Arman, scanf("%19s", name) reads only MD, while fgets() can read the complete line.

4. Finding String Length

The strlen() function returns the number of characters before the null terminator. It is declared in <string.h>. 

#include <stdio.h>
#include <string.h>

int main(void)
{
    char name[] = "ARMAN";

    printf("Length = %zu\n", strlen(name));

    return 0;
}

Output:

Length = 5

Finding the length using a loop

#include <stdio.h>

int main(void)
{
    char name[] = "ARMAN";
    int i = 0;

    while (name[i] != '\0')
    {
        i++;
    }

    printf("Length = %d\n", i);

    return 0;
}
strlen() does not count the null terminator. The loop stops when it reaches '\0'.

5. Traversing a String

Traversing means visiting the characters of a string one by one. 

#include <stdio.h>

int main(void)
{
    char word[] = "CODE";
    int i;

    for (i = 0; word[i] != '\0'; i++)
    {
        printf("%c\n", word[i]);
    }

    return 0;
}

Output:

C
O
D
E

The condition word[i] != '\0' allows the loop to stop at the end of the string.

6. Changing Letter Case

The functions toupper() and tolower() are declared in <ctype.h>.

Convert lowercase letters to uppercase

#include <stdio.h>
#include <ctype.h>

int main(void)
{
    char word[] = "arman";
    int i;

    for (i = 0; word[i] != '\0'; i++)
    {
        word[i] = (char)toupper((unsigned char)word[i]);
    }

    printf("%s\n", word);

    return 0;
}

Output:

ARMAN

Convert uppercase letters to lowercase

word[i] = (char)tolower((unsigned char)word[i]);

Use this statement inside a loop that visits each character. Include <ctype.h> in your program.

7. Reversing a String

Reversing a string means displaying its characters in the opposite order. 

#include <stdio.h>
#include <string.h>

int main(void)
{
    char name[] = "ARMAN";
    int i;

    for (i = (int)strlen(name) - 1; i >= 0; i--)
    {
        printf("%c", name[i]);
    }

    printf("\n");

    return 0;
}

Output:

NAMRA
The loop starts at strlen(name) - 1 because string indexes start at zero. The last character is at index length - 1.

This example displays the string backwards without modifying the original array.

8. Comparing Strings with strcmp()

Use strcmp() from <string.h> to compare two strings. 

#include <stdio.h>
#include <string.h>

int main(void)
{
    char a[] = "apple";
    char b[] = "apple";

    if (strcmp(a, b) == 0)
    {
        printf("Strings are equal\n");
    }
    else
    {
        printf("Strings are different\n");
    }

    return 0;
}

Output:

Strings are equal

Remember these results:

  • strcmp(a, b) == 0: the strings are equal.
  • strcmp(a, b) < 0: the first string compares before the second.
  • strcmp(a, b) > 0: the first string compares after the second.
Do not normally compare string contents using a == b. Use strcmp(a, b) == 0.

9. Joining Strings with strcat()

The strcat() function appends one string to another. It is declared in <string.h>. 

#include <stdio.h>
#include <string.h>

int main(void)
{
    char first[30] = "Hello ";
    char second[] = "Arman";

    strcat(first, second);

    printf("%s\n", first);

    return 0;
}

Output:

Hello Arman
The destination array must have enough space for the combined characters and the terminating '\0'. Otherwise, the program can have undefined behavior.

10. Common Mistakes

Mistake 1: Forgetting the null terminator

char name[] = {'A', 'r', 'm', 'a', 'n'};

This array has no null terminator, so it is not a valid null-terminated C string. Use "Arman" or add '\0' explicitly.

Mistake 2: Using the wrong loop condition

for (i = 0; name[i] != '\0'; i++)
{
    printf("%c", name[i]);
}

Stop at the null terminator rather than reading beyond the end of the array.

Mistake 3: Comparing strings with ==

if (strcmp(a, b) == 0)
{
    printf("Equal");
}

Use strcmp() when you want to compare string contents.

Mistake 4: Reading a sentence with scanf("%s", ...)

scanf("%s", name) stops at whitespace. Use fgets() when you need to read a line containing spaces.

Mistake 5: Using strcat() without enough space

Always ensure the destination array can hold the resulting string and its null terminator.
