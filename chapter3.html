Chapter 3: Operators in C

Learn how to perform calculations, comparisons, and logical operations.

1. What Are Operators?

Operators are symbols used to perform operations on variables and values in a C program.

For example:

int a = 10;
int b = 5;
int sum = a + b;

printf("%d", sum);

Output:

15

Here, + is an arithmetic operator that adds the values of a and b.

2. Arithmetic Operators

Arithmetic operators perform mathematical calculations.

Operator Name Example Result
+ Addition 10 + 3 13
- Subtraction 10 - 3 7
* Multiplication 10 * 3 30
/ Division 10 / 3 3 (integer division)
% Modulus 10 % 3 1 (remainder)
Remember: When both operands are integers, integer division discards the fractional part. For example, 10 / 3 produces 3. The modulus operator % gives the remainder and is used with integer operands in C.

Example Program

#include <stdio.h>

int main()
{
    int a = 10, b = 3;

    printf("Addition = %d\n", a + b);
    printf("Subtraction = %d\n", a - b);
    printf("Multiplication = %d\n", a * b);
    printf("Division = %d\n", a / b);
    printf("Remainder = %d\n", a % b);

    return 0;
}

Output:

Addition = 13
Subtraction = 7
Multiplication = 30
Division = 3
Remainder = 1

3. Relational Operators

Relational operators compare two values. A comparison produces 1 when true and 0 when false in C.

Operator Meaning Example
== Equal to 5 == 5 → 1
!= Not equal to 5 != 3 → 1
> Greater than 8 > 4 → 1
< Less than 3 < 2 → 0
>= Greater than or equal to 5 >= 5 → 1
<= Less than or equal to 4 <= 2 → 0

Example Program

#include <stdio.h>

int main()
{
    int a = 10, b = 5;

    printf("%d\n", a > b);
    printf("%d\n", a == b);
    printf("%d\n", a != b);

    return 0;
}

Output:

1
0
1
Important: = assigns a value, while == compares two values.

4. Logical Operators

Logical operators combine conditions or reverse a condition.

Operator Name Meaning
&& Logical AND True when both conditions are true.
|| Logical OR True when at least one condition is true.
! Logical NOT Reverses a condition's truth value.

Example Program

#include <stdio.h>

int main()
{
    int age = 20;

    printf("%d\n", age >= 18 && age <= 60);
    printf("%d\n", age < 18 || age > 60);
    printf("%d\n", !(age >= 18));

    return 0;
}

Output:

1
0
0

The first expression is true because age is at least 18 and at most 60. The second and third expressions are false.

5. Assignment Operators

Assignment operators assign or update values in variables.

Operator Example Equivalent expression
= a = 10 Assign 10 to a
+= a += 5 a = a + 5
-= a -= 5 a = a - 5
*= a *= 2 a = a * 2
/= a /= 2 a = a / 2
%= a %= 3 a = a % 3

Example Program

#include <stdio.h>

int main()
{
    int a = 10;

    a += 5;
    printf("%d\n", a);

    a -= 3;
    printf("%d\n", a);

    return 0;
}

Output:

15
12

6. Increment and Decrement Operators

The increment operator ++ increases a variable by one. The decrement operator -- decreases a variable by one. 

int a = 5;

a++;
printf("%d\n", a);

a--;
printf("%d\n", a);

Output:

6
5

Prefix and Postfix

  • ++a: increments first, then produces the new value.
  • a++: produces the old value, then increments.
  • --a: decrements first, then produces the new value.
  • a--: produces the old value, then decrements.
int a = 5;

printf("%d\n", a++);
printf("%d\n", a);

printf("%d\n", ++a);

Output:

5
6
7

7. Operator Precedence

Operator precedence determines which operation is performed first in an expression. 

int result = 2 + 3 * 4;
printf("%d", result);

Output:

14

Multiplication is performed before addition, so the result is 2 + 12 = 14.

Use parentheses when you want to make the intended order clear: 

int result = (2 + 3) * 4;
printf("%d", result);

Output:

20
