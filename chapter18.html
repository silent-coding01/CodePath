Chapter 18: Command-Line Arguments in C

Learn how to pass information to a program when starting it.

1. What Are Command-Line Arguments?

Command-line arguments are values supplied to a program when it is started from a command-line interface, such as Windows Command Prompt.

Normally, a program may ask for input using scanf(). With command-line arguments, you can provide some input before the program begins executing.

Example

program.exe Arman 20

Here, Arman and 20 are arguments supplied when the program is launched.

Command-line arguments are useful for passing filenames, numbers, configuration options, and other information to programs.

2. The main() Function with Arguments

To receive command-line arguments, write main() with two parameters: 

int main(int argc, char *argv[])

Understanding argc

argc represents the argument count. It tells you how many strings are available in argv, including the program name at index zero.

Understanding argv

argv is an array of pointers to strings containing the command-line arguments.

  • argv[0] — Program name or invocation name.
  • argv[1] — First argument supplied by the user.
  • argv[2] — Second argument supplied by the user.
For a portable hosted C program, use int main(int argc, char *argv[]). The strings in argv are not automatically integers; they are strings.

3. First Program: Display Arguments

#include <stdio.h>

int main(int argc, char *argv[])
{
    int i;

    printf("Argument count: %d\n", argc);

    for (i = 0; i < argc; i++)
    {
        printf("argv[%d] = %s\n", i, argv[i]);
    }

    return 0;
}

Compile the Program

Save the file as args.c. Open Command Prompt in the directory containing the file and run: 

gcc args.c -o args.exe

Run with Arguments

args.exe Arman 20

Example Output

Argument count: 3
argv[0] = args.exe
argv[1] = Arman
argv[2] = 20
The exact value printed for argv[0] can vary depending on how the program is launched. The example shows a common result.

4. Accessing a Specific Argument

You can use an individual argument by referring to its index. Always check argc before accessing an argument. 

#include <stdio.h>

int main(int argc, char *argv[])
{
    if (argc < 2)
    {
        printf("Please provide your name.\n");
        return 1;
    }

    printf("Hello, %s!\n", argv[1]);

    return 0;
}

Run

args.exe Arman

Output

Hello, Arman!

If you run the program without an additional argument, it displays a message instead of accessing a missing argument.

5. Command-Line Arguments Are Strings

Even when you supply a number, the corresponding argv element is a string.

For example:

args.exe 25

The value argv[1] contains the characters "25", not the integer 25.

To convert a valid integer string into an integer, you can use strtol() from <stdlib.h>. 

#include <stdio.h>
#include <stdlib.h>
#include <errno.h>

int main(int argc, char *argv[])
{
    char *end;
    long number;

    if (argc != 2)
    {
        printf("Usage: args.exe number\n");
        return 1;
    }

    errno = 0;
    number = strtol(argv[1], &end, 10);

    if (argv[1][0] == '\0' || *end != '\0' || errno != 0)
    {
        printf("Please provide a valid integer.\n");
        return 1;
    }

    printf("Number = %ld\n", number);

    return 0;
}

Run

args.exe 250

Output

Number = 250
strtol() supports error checking, unlike simply assuming every argument contains a valid number.

6. Adding Two Numbers

This example accepts two integer arguments and displays their sum. 

#include <stdio.h>
#include <stdlib.h>
#include <errno.h>

int main(int argc, char *argv[])
{
    char *end1;
    char *end2;
    long a;
    long b;

    if (argc != 3)
    {
        printf("Usage: args.exe number1 number2\n");
        return 1;
    }

    errno = 0;
    a = strtol(argv[1], &end1, 10);

    if (argv[1][0] == '\0' || *end1 != '\0' || errno != 0)
    {
        printf("First argument is not a valid integer.\n");
        return 1;
    }

    errno = 0;
    b = strtol(argv[2], &end2, 10);

    if (argv[2][0] == '\0' || *end2 != '\0' || errno != 0)
    {
        printf("Second argument is not a valid integer.\n");
        return 1;
    }

    printf("Sum = %ld\n", a + b);

    return 0;
}

Run

args.exe 10 20

Output

Sum = 30
This beginner example does not check for overflow when adding two valid long values. Real applications should check that the sum is representable before adding.

7. Advantages of Command-Line Arguments

  • Provide input without interactive prompts.
  • Make programs convenient to automate with scripts.
  • Allow users to specify filenames and options.
  • Make it easy to run the same program with different inputs.

8. Common Mistakes

  • Accessing argv[1] without checking argc.
  • Assuming command-line arguments are automatically integers.
  • Using an incorrect argument index.
  • Forgetting that argv[0] normally refers to the program invocation name.
  • Failing to validate arguments before using them.
