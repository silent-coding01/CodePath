CHAPTER 01

Introduction to C Programming

Start your programming journey by learning the fundamentals of C, one concept at a time.

1. What Is Programming?

Programming is the process of writing instructions that tell a computer what to do.

Real-life example

Imagine giving someone instructions to make tea: boil water, add tea leaves, add milk, and serve. A computer program also follows instructions to complete a task.

However, computers require instructions written in a programming language they can process.

2. What Is C?

C is a general-purpose programming language developed by Dennis Ritchie at Bell Laboratories in the early 1970s.

C is widely used for learning programming fundamentals, systems programming, embedded systems, and other performance-sensitive applications.

Why learn C?

  • It teaches important programming fundamentals.
  • It helps you understand memory and data types.
  • It develops logical problem-solving skills.
  • It provides a foundation for learning other languages.

3. What Is a Compiler?

A compiler translates source code written in a programming language into a form that can be executed by a computer.

Real-life example

Imagine a translator converting a message from one language into another. A compiler performs a related translation task for computer programs, although the details are different.

GCC is one commonly used compiler for C.

4. Your First C Program

Here is a simple C program:

#include <stdio.h>

int main()
{
    printf("Hello, World!");

    return 0;
}

Understanding the code

  • #include <stdio.h> provides declarations for standard input/output functions such as printf().
  • int main() defines the main function where execution of this program begins.
  • printf() displays text on the screen.
  • return 0; indicates successful completion of the program.

Output

Hello, World!
