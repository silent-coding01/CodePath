Storage Classes in C

Storage classes help determine a variable's scope, lifetime, visibility, and storage behavior.

Learning goal: Understand auto, register, static, and extern.

1. What Is a Storage Class?

A storage class tells the compiler important information about how a variable or function is used.

Important concepts include:

  • Scope: Where a variable can be accessed.
  • Lifetime: How long the variable exists.
  • Linkage: Whether a name can refer to the same entity across different scopes or source files.
Remember: scope, lifetime, and linkage are related concepts, but they do not mean the same thing.

2. The auto Storage Class

Local variables declared inside a block normally have automatic storage duration. The keyword auto can explicitly declare this storage class, although it is rarely written in ordinary C programs. 

#include <stdio.h>

int main(void)
{
    auto int number = 10;

    printf("%d", number);

    return 0;
}

Output:

10
  • The variable is local to its block.
  • Its lifetime normally ends when the block exits.
  • A new entry into the block creates a new instance of the variable.

3. The register Storage Class

The register keyword historically suggests that a variable should be stored in a CPU register for faster access. The compiler decides how to allocate storage and may ignore the hint. 

#include <stdio.h>

int main(void)
{
    register int i;

    for (i = 1; i <= 5; i++)
    {
        printf("%d ", i);
    }

    return 0;
}

Output:

1 2 3 4 5
In standard C, you cannot use the address-of operator (&) on an object declared with the register storage-class specifier.

4. The static Storage Class

A local variable declared with static retains its value between function calls. It is initialized only once. 

#include <stdio.h>

void count(void)
{
    static int number = 0;

    number++;

    printf("%d ", number);
}

int main(void)
{
    count();
    count();
    count();

    return 0;
}

Output:

1 2 3

Without static, a normal local variable would be initialized again whenever execution enters its block.

Another important use of static

At file scope, static gives a function or variable internal linkage, making its name available only within that source file.

5. The extern Storage Class

The extern keyword declares an object or function that is defined elsewhere. It is commonly used to access a global variable defined in another part of a program. 

#include <stdio.h>

int total = 100;

int main(void)
{
    extern int total;

    printf("%d", total);

    return 0;
}

Output:

100

Here, the file-scope variable total is defined before main(). The declaration inside main() refers to that variable.

An extern declaration does not normally create a new variable definition. It declares an entity defined elsewhere.

6. Comparison of Storage Classes

auto      - Ordinary block-local variable behavior
register  - Automatic storage with a register hint
static    - Static storage duration; local values persist
extern    - Declares an entity defined elsewhere

Important: These keywords are not interchangeable. Each has a different purpose.

7. Common Mistakes

  • Assuming static local variables reset on every function call.
  • Assuming register guarantees faster execution.
  • Confusing a variable's scope with its lifetime.
  • Using extern as if it always defines a new variable.
  • Thinking a file-scope static variable is accessible from every source file.

9. Coding Challenges

Easy: Static Counter

Write a function named counter() that uses a static integer variable. Every time the function is called, increase the variable by one and print its value.

Medium: Function Calls

Create a function that uses a static variable initialized to 10. Call the function four times and observe how its value changes.

Hard: Two Source Files

Create two C source files. Define a global integer in the first file and use an extern declaration in the second file to access it. Compile and run both files together.
