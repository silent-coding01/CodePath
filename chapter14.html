Enumerations and Typedef in C

Learn how to create named integer constants with enum and how to create convenient type aliases using typedef.

Learning goals: Understand enumeration constants, their values, typedef aliases, and how both features can be used with structures.

1. What Is an Enumeration?

An enumeration is a user-defined type that defines a set of named integer constants.

We use the keyword enum to define an enumeration. 

enum Day
{
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY,
    SUNDAY
};

By default, the first enumerator has value 0, and each subsequent enumerator increases by 1.

  • MONDAY = 0
  • TUESDAY = 1
  • WEDNESDAY = 2
  • THURSDAY = 3
Enumeration constants make programs easier to read than unexplained numeric values.

2. Declaring and Using an enum

#include <stdio.h>

enum Day
{
    MONDAY,
    TUESDAY,
    WEDNESDAY
};

int main(void)
{
    enum Day today = TUESDAY;

    printf("%d\n", today);

    return 0;
}

Output:

1

The variable today stores the enumeration value corresponding to TUESDAY, which is 1 in this example.

printf("%d", today) prints the integer value, not the word "TUESDAY".

3. Assigning Values to enum Constants

You can explicitly assign integer values to enumerators. 

#include <stdio.h>

enum Status
{
    FAILED = 0,
    SUCCESS = 1,
    PENDING = 5
};

int main(void)
{
    enum Status result = PENDING;

    printf("%d\n", result);

    return 0;
}

Output:

5

If an enumerator has an explicit value, the next enumerator without an explicit value normally receives the preceding value plus one. 

enum Level
{
    LOW = 2,
    MEDIUM,
    HIGH
};

Here, the values are:

  • LOW = 2
  • MEDIUM = 3
  • HIGH = 4

4. Using enum with switch

Enumerations work well with switch statements. 

#include <stdio.h>

enum TrafficLight
{
    RED,
    YELLOW,
    GREEN
};

int main(void)
{
    enum TrafficLight light = GREEN;

    switch (light)
    {
        case RED:
            printf("Stop");
            break;

        case YELLOW:
            printf("Wait");
            break;

        case GREEN:
            printf("Go");
            break;
    }

    return 0;
}

Output:

Go

5. Advantages of enum

  • Makes code easier to read.
  • Provides meaningful names for related integer constants.
  • Works naturally with switch statements.
  • Makes groups of related values easier to maintain.
In C, enumeration constants are integer constants. An enum variable is not automatically restricted to only the named enumerator values in every context.

6. What Is typedef?

The typedef keyword creates an alias for an existing type name. It does not create an entirely new distinct type. 

typedef unsigned int uint;

int main(void)
{
    uint age = 20;

    return 0;
}

Here, uint is another name for unsigned int.

Remember: typedef creates a type alias; it does not declare a variable by itself.

7. typedef with Structures

Without typedef, you generally write struct Student when declaring a variable. 

struct Student
{
    int roll;
    float marks;
};

struct Student s1;

With typedef, you can create a shorter type name. 

#include <stdio.h>

typedef struct
{
    int roll;
    float marks;
} Student;

int main(void)
{
    Student s1 = {101, 89.5f};

    printf("Roll: %d\n", s1.roll);
    printf("Marks: %.1f\n", s1.marks);

    return 0;
}

Output:

Roll: 101
Marks: 89.5

Now you can declare variables using Student without writing struct each time.

8. typedef with enum

You can also create an alias for an enumeration type. 

#include <stdio.h>

typedef enum
{
    SMALL,
    MEDIUM,
    LARGE
} Size;

int main(void)
{
    Size shirt = LARGE;

    printf("%d\n", shirt);

    return 0;
}

Output:

2

The name Size can be used directly as the type name.

9. typedef with Pointers

A type alias can also represent a pointer type. 

#include <stdio.h>

typedef int* IntPointer;

int main(void)
{
    int number = 50;

    IntPointer ptr = &number;

    printf("%d\n", *ptr);

    return 0;
}

Output:

50
Be careful with pointer typedefs: IntPointer a, b; declares both a and b as pointers to int. This differs from writing int *a, b;, where only a is a pointer.

10. enum vs typedef

  • enum defines an enumeration type and named integer constants.
  • typedef creates an alias for a type name.
  • enum can introduce named choices such as RED, GREEN, and BLUE.
  • typedef can make long type declarations easier to use.
enum Color
{
    RED,
    GREEN,
    BLUE
};

typedef unsigned long ulong;

11. Common Mistakes

  • Forgetting the semicolon after an enum definition.
  • Assuming the first enumerator starts at 1 instead of 0.
  • Assuming printing an enum automatically prints its name.
  • Confusing a typedef alias with a variable declaration.
  • Assuming typedef creates a completely separate type.
