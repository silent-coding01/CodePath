CHAPTER 02

Variables and Data Types

Learn how C stores information and works with different kinds of data.

1. What Is a Variable?

A variable is a named storage location used to hold a value that a program can use.

Real-life example

Imagine a box labelled "age". If the box contains the number 20, the variable age stores the value 20.

int age = 20;

Here:

  • int specifies the data type.
  • age is the variable name.
  • 20 is the initial value.
  • ; terminates the statement.

2. Declaring and Initializing Variables

Declaration tells the compiler a variable's name and type. Initialization gives it an initial value.

Declaration

int marks;

Initialization

int marks = 85;

Changing a value

int score = 10;
score = 25;

printf("%d", score);

Output:

25

The variable's value changes from 10 to 25.

3. Rules for Naming Variables

  • A variable name can contain letters, digits and underscores.
  • It cannot begin with a digit.
  • Spaces are not allowed.
  • C keywords such as int cannot be variable names.
  • C variable names are case-sensitive: age and Age are different.

Valid names

age
student_marks
number2

Invalid names

2number
student marks
float

float is invalid as a variable name because it is a C keyword.

4. Basic Data Types in C

A data type determines what kind of value a variable can represent.

Integer — int

int age = 20;
printf("%d", age);

Output:

20

Character — char

char grade = 'A';
printf("%c", grade);

Output:

A

Decimal number — float

float price = 12.5f;
printf("%f", price);

Output:

12.500000

Double-precision decimal — double

double pi = 3.14159;
printf("%f", pi);

Output:

3.141590

These examples use common format specifiers: %d for int, %c for char, and %f for floating-point output.

5. Taking Input from the User

The scanf() function can read input into a variable. Use & before ordinary variables such as age and marks.

#include <stdio.h>

int main()
{
    int age;

    printf("Enter your age: ");
    scanf("%d", &age);

    printf("Your age is %d", age);

    return 0;
}

Example run:

Enter your age: 20
Your age is 20
