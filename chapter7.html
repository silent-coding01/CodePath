1. What Is an Array?

An array is a collection of elements of the same data type stored in consecutive array positions. Each element can be accessed using its index.

Why do we need arrays?

Suppose we want to store the marks of five students. Without an array, we might declare five separate variables. 

int mark1 = 70;
int mark2 = 85;
int mark3 = 90;
int mark4 = 65;
int mark5 = 80;

This works for five values, but it becomes inconvenient when we need to store hundreds of values.

With an array, we can write:

int marks[5] = {70, 85, 90, 65, 80};

We can then process all five marks using a loop.

Remember: A normal integer array stores integer elements. It does not automatically store unrelated data types such as strings and floating-point values in the same array.

Visual representation

Index 480

Each box represents an element. The index identifies its position in the array.

2. Declaration and Initialization

Array declaration

int numbers[5];

This declares an array that can hold five integers. If it is a local array and no initial values are provided, its elements have indeterminate values until initialized. Do not read those values before assigning them.

Array initialization

int numbers[5] = {10, 20, 30, 40, 50};

We can also let C determine the size from the initializer:

int numbers[] = {10, 20, 30, 40, 50};

The compiler determines that the array has five elements.

Partial initialization

int numbers[5] = {10, 20};

The resulting elements are {10, 20, 0, 0, 0}. Elements without explicit initializers are initialized to zero.

Common declaration examples

int ages[10];
float prices[5];
char letters[4];

The number inside the brackets specifies the number of elements, not the last index.

3. Indexing and Modifying Elements

In C, array indexing begins at zero. An array containing five elements has valid indices from zero through four.

Expression Value
numbers[0]10
numbers[1]20
numbers[2]30
numbers[3]40
numbers[4]50
#include <stdio.h>

int main(void)
{
    int numbers[5] = {10, 20, 30, 40, 50};

    printf("%d\n", numbers[0]);
    printf("%d\n", numbers[2]);

    numbers[2] = 99;

    printf("%d\n", numbers[2]);

    return 0;
}
10
30
99

Important: Accessing an array element outside its valid range causes undefined behavior. For an array of five elements, numbers[5] is not valid.

4. Taking Input and Printing an Array

A loop lets us read or print each element without repeating the same statement many times. 

#include <stdio.h>

int main(void)
{
    int a[5];
    int i;

    printf("Enter 5 numbers: ");

    for (i = 0; i < 5; i++)
    {
        scanf("%d", &a[i]);
    }

    printf("Array elements: ");

    for (i = 0; i < 5; i++)
    {
        printf("%d ", a[i]);
    }

    return 0;
}

Sample input:

10 20 30 40 50

Sample output:

Array elements: 10 20 30 40 50

&a[i] provides the address of the element where scanf will store the entered integer.

Check that input succeeds in production programs. This introductory example assumes the user enters five valid integers.

5. Traversing an Array

Traversal means visiting array elements one by one. It is the foundation of many array operations.

6. Sum and Average of Array Elements

Calculate the sum

#include <stdio.h>

int main(void)
{
    int a[5] = {10, 20, 30, 40, 50};
    int i;
    int sum = 0;

    for (i = 0; i < 5; i++)
    {
        sum = sum + a[i];
    }

    printf("Sum = %d\n", sum);

    return 0;
}
Sum = 150

We initialize sum to zero, then add every element to it.

Calculate the average

#include <stdio.h>

int main(void)
{
    int marks[5] = {70, 80, 90, 60, 100};
    int i;
    int sum = 0;
    double average;

    for (i = 0; i < 5; i++)
    {
        sum += marks[i];
    }

    average = (double)sum / 5;

    printf("Sum = %d\n", sum);
    printf("Average = %.2f\n", average);

    return 0;
}
Sum = 400
Average = 80.00

The cast (double)sum allows the division to produce a fractional result when needed.

7. Find the Largest and Smallest Elements

Initialize both variables using the first array element. This works even when every element is negative. 

#include <stdio.h>

int main(void)
{
    int a[6] = {12, 45, 7, 89, 23, 4};
    int i;
    int largest = a[0];
    int smallest = a[0];

    for (i = 1; i < 6; i++)
    {
        if (a[i] > largest)
        {
            largest = a[i];
        }

        if (a[i] < smallest)
        {
            smallest = a[i];
        }
    }

    printf("Largest = %d\n", largest);
    printf("Smallest = %d\n", smallest);

    return 0;
}
Largest = 89
Smallest = 4

We start at index one because index zero already provides the initial largest and smallest values.

8. Searching for an Element

Linear search checks elements one by one until it finds the target or reaches the end of the array. 

#include <stdio.h>

int main(void)
{
    int a[5] = {15, 28, 42, 57, 63};
    int target = 42;
    int i;
    int found = 0;

    for (i = 0; i < 5; i++)
    {
        if (a[i] == target)
        {
            found = 1;
            break;
        }
    }

    if (found)
    {
        printf("Found at index %d\n", i);
    }
    else
    {
        printf("Not found\n");
    }

    return 0;
}
Found at index 2

The break statement ends the search after the first matching element.

9. Count Even and Odd Elements

#include <stdio.h>

int main(void)
{
    int a[6] = {2, 7, 10, 13, 18, 21};
    int i;
    int even = 0;
    int odd = 0;

    for (i = 0; i < 6; i++)
    {
        if (a[i] % 2 == 0)
        {
            even++;
        }
        else
        {
            odd++;
        }
    }

    printf("Even = %d\n", even);
    printf("Odd = %d\n", odd);

    return 0;
}
Even = 3
Odd = 3

The remainder operator % 2 determines whether an integer is even or odd.

10. Reverse an Array

To reverse an array in place, exchange the first element with the last, the second with the second-last, and so on. 

#include <stdio.h>

int main(void)
{
    int a[5] = {10, 20, 30, 40, 50};
    int i;
    int temp;

    for (i = 0; i < 5 / 2; i++)
    {
        temp = a[i];
        a[i] = a[4 - i];
        a[4 - i] = temp;
    }

    for (i = 0; i < 5; i++)
    {
        printf("%d ", a[i]);
    }

    return 0;
}
50 40 30 20 10

We only need to perform swaps for half the array. Swapping every element again would undo the reversal.

11. Copying and Merging Arrays

Copy an array

#include <stdio.h>

int main(void)
{
    int a[4] = {5, 10, 15, 20};
    int b[4];
    int i;

    for (i = 0; i < 4; i++)
    {
        b[i] = a[i];
    }

    for (i = 0; i < 4; i++)
    {
        printf("%d ", b[i]);
    }

    return 0;
}
5 10 15 20

Merge two arrays

#include <stdio.h>

int main(void)
{
    int a[3] = {1, 2, 3};
    int b[3] = {4, 5, 6};
    int c[6];
    int i;

    for (i = 0; i < 3; i++)
    {
        c[i] = a[i];
        c[i + 3] = b[i];
    }

    for (i = 0; i < 6; i++)
    {
        printf("%d ", c[i]);
    }

    return 0;
}
1 2 3 4 5 6

This example concatenates two arrays. It does not sort their combined values.

12. Sorting an Array: Bubble Sort

Bubble sort compares adjacent elements and swaps them when they are in the wrong order. 

#include <stdio.h>

int main(void)
{
    int a[5] = {40, 10, 50, 20, 30};
    int i, j, temp;

    for (i = 0; i < 4; i++)
    {
        for (j = 0; j < 4 - i; j++)
        {
            if (a[j] > a[j + 1])
            {
                temp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = temp;
            }
        }
    }

    for (i = 0; i < 5; i++)
    {
        printf("%d ", a[i]);
    }

    return 0;
}
10 20 30 40 50

How the algorithm works

  1. Compare two adjacent elements.
  2. Swap them if the left element is larger.
  3. Continue through the unsorted portion.
  4. Repeat until the array is sorted.

This beginner-friendly version has O(n²) time complexity in the average and worst cases.

13. Frequency and Duplicate Elements

Frequency means how many times a value appears in an array.

Count a target value

#include <stdio.h>

int main(void)
{
    int a[6] = {2, 5, 2, 7, 2, 5};
    int target = 2;
    int count = 0;
    int i;

    for (i = 0; i < 6; i++)
    {
        if (a[i] == target)
        {
            count++;
        }
    }

    printf("%d appears %d times\n", target, count);

    return 0;
}
2 appears 3 times

Identify duplicate values

#include <stdio.h>

int main(void)
{
    int a[6] = {2, 5, 2, 7, 5, 9};
    int i, j, k;
    int alreadyPrinted;

    for (i = 0; i < 6; i++)
    {
        alreadyPrinted = 0;

        for (k = 0; k < i; k++)
        {
            if (a[k] == a[i])
            {
                alreadyPrinted = 1;
                break;
            }
        }

        if (alreadyPrinted)
        {
            continue;
        }

        for (j = i + 1; j < 6; j++)
        {
            if (a[i] == a[j])
            {
                printf("%d ", a[i]);
                break;
            }
        }
    }

    return 0;
}
2 5

The program prints each duplicated value once, even if it appears more than twice.

14. Insertion and Deletion

C arrays have a fixed size after declaration. We can still insert or delete values logically by shifting elements, provided the allocated array has enough capacity.

Insert at an index

#include <stdio.h>

int main(void)
{
    int a[6] = {10, 20, 30, 40, 50};
    int n = 5;
    int position = 2;
    int value = 99;
    int i;

    if (position < 0 || position > n || n >= 6)
    {
        printf("Invalid insertion\n");
        return 0;
    }

    for (i = n; i > position; i--)
    {
        a[i] = a[i - 1];
    }

    a[position] = value;
    n++;

    for (i = 0; i < n; i++)
    {
        printf("%d ", a[i]);
    }

    return 0;
}
10 20 99 30 40 50

Delete at an index

#include <stdio.h>

int main(void)
{
    int a[5] = {10, 20, 30, 40, 50};
    int n = 5;
    int position = 2;
    int i;

    if (position < 0 || position >= n)
    {
        printf("Invalid deletion\n");
        return 0;
    }

    for (i = position; i < n - 1; i++)
    {
        a[i] = a[i + 1];
    }

    n--;

    for (i = 0; i < n; i++)
    {
        printf("%d ", a[i]);
    }

    return 0;
}
10 20 40 50

These examples use zero-based indices. The deletion operation decreases the logical element count, but the allocated array capacity remains unchanged.

15. Rotate an Array to the Right

A right rotation by one position moves the last element to the beginning and shifts all other elements one position right. 

#include <stdio.h>

int main(void)
{
    int a[5] = {1, 2, 3, 4, 5};
    int i;
    int last = a[4];

    for (i = 4; i > 0; i--)
    {
        a[i] = a[i - 1];
    }

    a[0] = last;

    for (i = 0; i < 5; i++)
    {
        printf("%d ", a[i]);
    }

    return 0;
}
5 1 2 3 4

16. Find the Second-Largest Distinct Element

The second-largest distinct element must be smaller than the largest value and different from it. 

#include <stdio.h>

int main(void)
{
    int a[6] = {12, 45, 7, 45, 32, 20};
    int largest = a[0];
    int second = 0;
    int hasSecond = 0;
    int i;

    for (i = 1; i < 6; i++)
    {
        if (a[i] > largest)
        {
            second = largest;
            largest = a[i];
            hasSecond = 1;
        }
        else if (a[i] < largest)
        {
            if (!hasSecond || a[i] > second)
            {
                second = a[i];
                hasSecond = 1;
            }
        }
    }

    if (hasSecond)
    {
        printf("Second largest = %d\n", second);
    }
    else
    {
        printf("No second-largest distinct value\n");
    }

    return 0;
}
Second largest = 32

Notice that another occurrence of 45 is not considered the second-largest distinct value. The example also handles arrays whose values are all equal.

17. Passing Arrays to Functions

Arrays can be passed to functions so that the function can process their elements. In a function parameter, an array declaration such as int a[] is adjusted to a pointer parameter. 

#include <stdio.h>

void display(int a[], int size)
{
    int i;

    for (i = 0; i < size; i++)
    {
        printf("%d ", a[i]);
    }
}

int sumArray(int a[], int size)
{
    int i;
    int sum = 0;

    for (i = 0; i < size; i++)
    {
        sum += a[i];
    }

    return sum;
}

int main(void)
{
    int numbers[4] = {10, 20, 30, 40};

    display(numbers, 4);

    printf("\nSum = %d\n", sumArray(numbers, 4));

    return 0;
}
10 20 30 40
Sum = 100

The function receives access to the original array elements. Changes made through the parameter can affect the original array. The function does not automatically know the array's length, so we pass the size separately.

18. Two-Dimensional Arrays

A two-dimensional array organizes values into rows and columns. It is often used to represent a matrix or a table. 

int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
Column 0Column 1Column 2
Row 0123
Row 1456

For example, matrix[1][2] is 6 because it refers to row 1 and column 2, with both indices starting at zero.

Print a matrix

#include <stdio.h>

int main(void)
{
    int a[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    int i, j;

    for (i = 0; i < 2; i++)
    {
        for (j = 0; j < 3; j++)
        {
            printf("%d ", a[i][j]);
        }

        printf("\n");
    }

    return 0;
}
1 2 3
4 5 6

Matrix addition

#include <stdio.h>

int main(void)
{
    int a[2][2] = {{1, 2}, {3, 4}};
    int b[2][2] = {{5, 6}, {7, 8}};
    int c[2][2];
    int i, j;

    for (i = 0; i < 2; i++)
    {
        for (j = 0; j < 2; j++)
        {
            c[i][j] = a[i][j] + b[i][j];
        }
    }

    for (i = 0; i < 2; i++)
    {
        for (j = 0; j < 2; j++)
        {
            printf("%d ", c[i][j]);
        }

        printf("\n");
    }

    return 0;
}

10 12

Transpose a matrix

#include <stdio.h>

int main(void)
{
    int a[2][3] = {{1, 2, 3}, {4, 5, 6}};
    int i, j;

    for (j = 0; j < 3; j++)
    {
        for (i = 0; i < 2; i++)
        {
            printf("%d ", a[i][j]);
        }

        printf("\n");
    }

    return 0;
}

2 5
3 6

Transposition exchanges the row and column positions. A matrix with two rows and three columns becomes a displayed matrix with three rows and two columns.

19. Common Array Mistakes

Mistake 1: Wrong loop boundary

int a[5] = {1, 2, 3, 4, 5};
int i;

for (i = 0; i <= 5; i++)
{
    printf("%d ", a[i]);
}

This loop attempts to access a[5], which is outside the valid index range. Use i < 5.

Mistake 2: Forgetting to initialize a sum

int sum;
sum += a[0];

If sum is an uninitialized local variable, reading its indeterminate value is not valid. Initialize it before accumulating: 

int sum = 0;

Mistake 3: Confusing an index with a value

i represents the current index in a loop. a[i] represents the element stored at that index.

Mistake 4: Using the wrong array size

If an array has five elements, the valid indices are 0, 1, 2, 3, and 4—not 1 through 5.

Mistake 5: Forgetting that array parameters don't carry size

When an array is passed to a function, its length is not automatically provided as part of the array parameter. Pass the element count explicitly or use another suitable size-management method.
