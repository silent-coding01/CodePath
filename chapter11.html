1. What Is a Pointer?

A pointer is an object that stores the address of another object or function, subject to the pointer's type.

Ordinary variables store values. Pointer variables store addresses that can be used to access other objects. 

int number = 25;
int *ptr = &number;

Here:

  • number stores the integer value 25.
  • &number gives the address of number.
  • ptr stores that address.
  • *ptr accesses the value at that address.

Remember: A pointer is not the same thing as the value it points to. The pointer stores an address; dereferencing it accesses the pointed-to object.

2. Understanding Memory and Addresses

When a program uses a variable, the variable occupies memory. Its address identifies where that object is located in the program's memory model.

Consider this example:

int age = 20;
int *ptr = &age;

Conceptually, we can represent the relationship like this:

Object What it contains
age The integer value 20
ptr The address of age
*ptr The value 20, accessed through ptr

The actual address depends on the program's execution. We should not assume that a variable always has a particular address.

A pointer's printed address is implementation-dependent. The relationship between the variables is what matters, not a specific hexadecimal number.

3. The Address Operator (&)

The unary & operator obtains the address of an object when that object is addressable. 

#include <stdio.h>

int main(void)
{
    int number = 50;

    printf("Value = %d\n", number);
    printf("Address = %p\n", (void *)&number);

    return 0;
}

Example output:

Value = 50
Address = 0x7ffd1234

The address above is illustrative. Your program will generally print a different address.

The %p format specifier is used to print a pointer value. Converting an object pointer to void * is appropriate for this use.

4. Pointer Declaration and Initialization

Declaring a pointer

int *p;
char *c;
float *f;
double *d;

These declarations create pointer variables with different pointed-to types.

An uninitialized local pointer must not be dereferenced. It does not automatically point to a valid object.

Initializing a pointer

#include <stdio.h>

int main(void)
{
    int number = 100;
    int *ptr = &number;

    printf("Number = %d\n", number);
    printf("Through pointer = %d\n", *ptr);

    return 0;
}
Number = 100
Through pointer = 100

Declaring multiple pointers

int *p, *q;

Both p and q are pointers to int. The asterisk binds to each declarator, so int *p, q; declares p as a pointer but q as an ordinary integer.

5. The Dereference Operator (*)

When a pointer refers to a valid object of the correct type, unary * lets us access that object. 

#include <stdio.h>

int main(void)
{
    int number = 75;
    int *ptr = &number;

    printf("%d\n", *ptr);

    return 0;
}
75

In int *ptr, the asterisk declares a pointer. In *ptr inside an expression, it dereferences the pointer.

Dereferencing a null pointer, an uninitialized pointer, or an invalid or dangling pointer is not safe and can cause undefined behavior.

6. Modify a Variable Through a Pointer

A pointer can be used to modify the object it points to. 

#include <stdio.h>

int main(void)
{
    int number = 10;
    int *ptr = &number;

    printf("Before = %d\n", number);

    *ptr = 99;

    printf("After = %d\n", number);

    return 0;
}
Before = 10
After = 99

The statement *ptr = 99; changes the value of the original variable because ptr points to number.

7. NULL Pointers

A null pointer intentionally represents that it does not point to an object or function. 

#include <stdio.h>

int main(void)
{
    int *ptr = NULL;

    if (ptr == NULL)
    {
        printf("Pointer is NULL\n");
    }

    return 0;
}
Pointer is NULL

Checking whether a pointer is null is useful before using it when null is an allowed state.

Never dereference a null pointer. A null pointer is not a valid address to an ordinary object.

8. Pointers and Functions

C passes function arguments by value. However, we can pass a pointer value to a function, allowing the function to modify the object that pointer refers to.

Example: Modify a variable

#include <stdio.h>

void changeValue(int *p)
{
    *p = 500;
}

int main(void)
{
    int number = 10;

    changeValue(&number);

    printf("%d\n", number);

    return 0;
}
500

Example: Swap two integers

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void)
{
    int x = 10;
    int y = 20;

    swap(&x, &y);

    printf("x = %d\n", x);
    printf("y = %d\n", y);

    return 0;
}
x = 20
y = 10

The function receives the addresses of x and y. Dereferencing its parameters lets it change those original variables.

9. Pointers and Arrays

In many expressions, an array name is converted to a pointer to its first element. Arrays and pointers are closely related, but they are not identical. 

#include <stdio.h>

int main(void)
{
    int a[4] = {10, 20, 30, 40};
    int *p = a;

    printf("%d\n", a[0]);
    printf("%d\n", *p);
    printf("%d\n", *(p + 1));

    return 0;
}
10
10
20

These expressions are equivalent for valid indices:

a[0] == *(a + 0)
a[1] == *(a + 1)
a[2] == *(a + 2)

An array is not a pointer variable. For example, you cannot assign a new address to an array name using a = p;.

10. Pointer Arithmetic

Adding one to a pointer to an array element moves it to the next element of the pointed-to type, not simply one byte forward. 

#include <stdio.h>

int main(void)
{
    int a[4] = {11, 22, 33, 44};
    int *p = a;

    printf("%d\n", *p);

    p++;

    printf("%d\n", *p);

    p++;

    printf("%d\n", *p);

    return 0;
}
11
22
33

Here, p advances from a[0] to a[1], then to a[2]. Pointer arithmetic is defined only within the same array object and one position past its end; the one-past position must not be dereferenced.

Traverse an array with a pointer

#include <stdio.h>

int main(void)
{
    int a[5] = {2, 4, 6, 8, 10};
    int *p;

    for (p = a; p < a + 5; p++)
    {
        printf("%d ", *p);
    }

    return 0;
}
2 4 6 8 10

11. Pointers and Strings

A C string is a sequence of characters terminated by the null character '\0'. Pointers can be used to read characters in a string. 

#include <stdio.h>

int main(void)
{
    char text[] = "CODE";
    char *p = text;

    while (*p != '\0')
    {
        printf("%c ", *p);
        p++;
    }

    return 0;
}
C O D E

Each iteration prints the current character and advances the pointer to the next character.

A string literal such as "CODE" should not be modified through a pointer. The example uses a modifiable character array instead.

12. Pointers to Pointers

A pointer to a pointer stores the address of another pointer. For example, int **pp is a pointer to a pointer to int. 

#include <stdio.h>

int main(void)
{
    int number = 25;
    int *p = &number;
    int **pp = &p;

    printf("%d\n", number);
    printf("%d\n", *p);
    printf("%d\n", **pp);

    return 0;
}
25
25
25

*p accesses number, while **pp follows pp to p and then follows p to number.

13. Dynamic Memory Allocation

Dynamic memory allocation allows a program to request memory while it is running. The standard library functions used for this are declared in <stdlib.h>.

Using malloc()

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n = 5;
    int i;
    int *a = malloc((size_t)n * sizeof *a);

    if (a == NULL)
    {
        printf("Memory allocation failed\n");
        return 1;
    }

    for (i = 0; i < n; i++)
    {
        a[i] = (i + 1) * 10;
    }

    for (i = 0; i < n; i++)
    {
        printf("%d ", a[i]);
    }

    printf("\n");

    free(a);
    a = NULL;

    return 0;
}
10 20 30 40 50

Important functions:

  • malloc() allocates a block of memory.
  • calloc() allocates memory for multiple elements and initializes all bytes to zero.
  • realloc() attempts to resize an allocated block.
  • free() releases allocated memory.

Always check whether allocation succeeded. Access only memory within the allocated range, and release allocated memory when it is no longer needed. Do not use a pointer to access memory after it has been freed.

14. Common Pointer Mistakes

Mistake 1: Uninitialized pointer

int *p;
*p = 10;   /* Incorrect */

p does not point to a known valid object. Initialize it to the address of a suitable object or to NULL before use.

Mistake 2: Dereferencing NULL

int *p = NULL;
printf("%d", *p);   /* Incorrect */

A null pointer must not be dereferenced.

Mistake 3: Returning the address of a local variable

int *badFunction(void)
{
    int x = 10;
    return &x;
}

The local variable's lifetime ends when the function returns. The returned pointer is therefore not valid for accessing x.

Mistake 4: Accessing beyond an array

int a[3] = {10, 20, 30};
int *p = a;

printf("%d", *(p + 3));

p + 3 is one position past the array. It may be formed, but it must not be dereferenced.

Mistake 5: Using freed memory

int *p = malloc(sizeof *p);

if (p != NULL)
{
    *p = 10;
    free(p);
    p = NULL;
}

Setting p to NULL after freeing helps prevent accidental use through that pointer. It does not fix other copies of the old pointer that might still exist.

16. Pointer Coding Challenges

Beginner

  1. Declare an integer and print its value and address.
  2. Use a pointer to print a variable's value.
  3. Change a variable's value using a pointer.

Intermediate

  1. Write a function that swaps two integers using pointers.
  2. Print every element of an array using pointer arithmetic.
  3. Find the sum of an array using a pointer and a loop.
  4. Count the characters in a string using a pointer.

Advanced

  1. Write a function that finds the largest array element using pointers.
  2. Allocate an integer array dynamically and calculate its average.
  3. Explain the difference between a null pointer and an uninitialized pointer.
  4. Explain why returning the address of a local variable is unsafe.

Study advice: Compile and run each complete C program using GCC. Change the values, predict the output, and then test your prediction.
