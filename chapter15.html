Dynamic Memory Allocation

Learn how to request memory while a C program is running, use it, resize it, and release it when it is no longer needed.

Learning goals: Understand malloc(), calloc(), realloc(), free(), pointers, and safe memory management.

1. What Is Dynamic Memory Allocation?

Dynamic memory allocation allows a program to request memory during execution instead of deciding the entire amount in advance.

For example, suppose a user enters how many student marks they want to store. Dynamic allocation lets the program request memory based on that number.

The functions used for dynamic memory allocation are declared in the stdlib.h header. 

#include <stdlib.h>
  • malloc() — allocates a block of memory.
  • calloc() — allocates memory for multiple elements and initializes all bytes to zero.
  • realloc() — changes the size of an allocated block.
  • free() — releases allocated memory.
Dynamically allocated memory remains allocated until it is released with free() or until the program terminates.

2. The malloc() Function

malloc() requests a block of memory of a specified size in bytes. The memory is uninitialized, so its contents must not be read before they are assigned suitable values.

Syntax:

pointer = malloc(number_of_bytes);

Example: Allocate memory for one integer

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *ptr = malloc(sizeof *ptr);

    if (ptr == NULL)
    {
        printf("Memory allocation failed.\n");
        return 1;
    }

    *ptr = 100;

    printf("Value = %d\n", *ptr);

    free(ptr);

    return 0;
}

Output:

Value = 100

Important points:

  • sizeof *ptr gives the size needed for the pointed-to integer.
  • malloc() returns a pointer to the allocated memory or NULL if the allocation fails.
  • Always check whether the allocation succeeded before using the memory.
  • Use free() when you no longer need the allocated block.

3. Dynamic Arrays with malloc()

You can allocate enough memory for an array after learning how many elements the user wants to store. 

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n, i;
    int *arr;

    printf("Enter number of elements: ");

    if (scanf("%d", &n) != 1 || n <= 0)
    {
        printf("Invalid size.\n");
        return 1;
    }

    arr = malloc((size_t)n * sizeof *arr);

    if (arr == NULL)
    {
        printf("Memory allocation failed.\n");
        return 1;
    }

    for (i = 0; i < n; i++)
    {
        printf("Enter element %d: ", i + 1);

        if (scanf("%d", &arr[i]) != 1)
        {
            printf("Invalid input.\n");
            free(arr);
            return 1;
        }
    }

    printf("Array elements: ");

    for (i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    free(arr);

    return 0;
}

Example output:

Enter number of elements: 3
Enter element 1: 10
Enter element 2: 20
Enter element 3: 30
Array elements: 10 20 30
The pointer can be indexed like an array: arr[i]. The allocated block must be large enough for every accessed element.

4. The calloc() Function

calloc() allocates memory for a number of elements and initializes all allocated bytes to zero.

Syntax:

pointer = calloc(number_of_elements, size_of_each_element);

Example

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int i;
    int *arr = calloc(5, sizeof *arr);

    if (arr == NULL)
    {
        printf("Memory allocation failed.\n");
        return 1;
    }

    for (i = 0; i < 5; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    free(arr);

    return 0;
}

Output:

0 0 0 0 0

Here, the allocated bytes are zero-initialized, resulting in zero values for these integer elements.

malloc() leaves allocated memory uninitialized, while calloc() initializes the allocated bytes to zero.

5. The realloc() Function

realloc() changes the size of a previously allocated memory block.

Syntax:

new_pointer = realloc(old_pointer, new_size);

Example: Increase array size

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *arr = malloc(3 * sizeof *arr);

    if (arr == NULL)
    {
        printf("Initial allocation failed.\n");
        return 1;
    }

    arr[0] = 10;
    arr[1] = 20;
    arr[2] = 30;

    int *temp = realloc(arr, 5 * sizeof *arr);

    if (temp == NULL)
    {
        printf("Resizing failed.\n");
        free(arr);
        return 1;
    }

    arr = temp;

    arr[3] = 40;
    arr[4] = 50;

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    free(arr);

    return 0;
}

Output:

10 20 30 40 50

The original three elements are preserved when the allocation grows. The additional memory is uninitialized, so we assign values to the new elements before reading them.

Do not directly overwrite your only pointer with realloc(), such as arr = realloc(arr, new_size);. If resizing fails, the original allocation would still exist but its pointer could be lost.

6. The free() Function

free() releases memory that was obtained through a dynamic memory allocation function. 

int *ptr = malloc(sizeof *ptr);

if (ptr != NULL)
{
    *ptr = 50;

    printf("%d\n", *ptr);

    free(ptr);
    ptr = NULL;
}

Setting the pointer to NULL after freeing it helps prevent accidental use of that pointer.

  • Free dynamically allocated memory when it is no longer needed.
  • Do not dereference a pointer after its memory has been freed.
  • Do not free the same allocation twice.
  • Do not call free() on ordinary local variables.

7. Memory Leaks and Dangling Pointers

Memory leak

A memory leak occurs when allocated memory is no longer accessible to the program but has not been released. 

int *ptr = malloc(sizeof *ptr);

/* If the program loses ptr without freeing the block,
   that allocated memory can leak. */

Dangling pointer

A dangling pointer refers to memory that is no longer valid, such as memory that has already been freed. 

int *ptr = malloc(sizeof *ptr);

if (ptr != NULL)
{
    *ptr = 10;
    free(ptr);
    ptr = NULL;
}
A useful habit is to release each allocation exactly once and avoid using pointers to memory after it has been freed.

8. malloc() vs calloc()

  • malloc(size) requests a specified number of bytes.
  • calloc(count, size) requests space for a number of elements.
  • malloc() does not initialize the allocated bytes.
  • calloc() initializes the allocated bytes to zero.

9. Common Mistakes

  • Forgetting to include stdlib.h.
  • Using allocated memory without checking for NULL.
  • Reading memory before assigning a valid value to it.
  • Forgetting to call free().
  • Accessing memory after it has been freed.
  • Using the wrong size when allocating an array.
  • Overwriting the original pointer when realloc() fails.

11. Coding Challenges

Easy: Allocate One Integer

Use malloc() to allocate memory for one integer. Store a number, print it, and release the memory.

Medium: Dynamic Array Sum

Ask the user for the number of elements. Allocate an array dynamically, input its elements, calculate their sum, print the sum, and free the memory.

Hard: Resize an Array

Allocate an array for three integers. Input the values, resize the array for five integers using realloc(), input two additional values, and display all five elements.
