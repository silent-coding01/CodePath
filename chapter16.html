1. What Is File Handling?

File handling allows a C program to store information in files and retrieve it later. Unlike ordinary variables, data saved in a file can remain available after the program ends.

Common file operations include:

  • Creating or opening a file
  • Writing data into a file
  • Reading data from a file
  • Appending new data
  • Closing a file
Important: File handling in C commonly uses functions declared in the <stdio.h> header.

2. The FILE Pointer

C uses a FILE pointer to work with an opened file. It keeps track of information needed for file operations. 

#include <stdio.h>

int main(void)
{
    FILE *fp;

    return 0;
}

Here, fp is a pointer that can refer to a file opened by the program.

3. Opening a File: fopen()

The fopen() function opens a file and returns a file pointer if successful. If it fails, it returns NULL. 

FILE *fp = fopen("data.txt", "w");

Common File Modes

  • "r" — Open an existing file for reading.
  • "w" — Open for writing; create or overwrite the file.
  • "a" — Open for appending; write at the end.
  • "r+" — Open an existing file for reading and writing.
  • "w+" — Open for reading and writing; create or overwrite.
  • "a+" — Open for reading and appending; create if needed.
Be careful: Opening an existing file with "w" erases its previous contents.

4. Writing to a File

The fprintf() function writes formatted text to a file. 

#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("data.txt", "w");

    if (fp == NULL)
    {
        printf("Unable to open file.\n");
        return 1;
    }

    fprintf(fp, "Hello, CodePath!\n");
    fprintf(fp, "Learning C file handling.\n");

    fclose(fp);

    printf("Data written successfully.\n");

    return 0;
}

How It Works

  1. Open data.txt in write mode.
  2. Check whether the file opened successfully.
  3. Write two lines using fprintf().
  4. Close the file using fclose().
The file is normally created in the program's working directory if it does not already exist.

5. Reading from a File

The fgets() function can read a line or a portion of a line from a file. 

#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("data.txt", "r");
    char line[100];

    if (fp == NULL)
    {
        printf("Unable to open file.\n");
        return 1;
    }

    while (fgets(line, sizeof(line), fp) != NULL)
    {
        printf("%s", line);
    }

    fclose(fp);

    return 0;
}

The loop continues while fgets() successfully reads data. When no more data can be read, it returns NULL.

Run the writing example first to create data.txt. Then run this reading example.

6. Appending Data to a File

Use "a" mode when you want to add new data without deleting the existing contents. 

#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("data.txt", "a");

    if (fp == NULL)
    {
        printf("Unable to open file.\n");
        return 1;
    }

    fprintf(fp, "This line was added later.\n");

    fclose(fp);

    printf("Data appended successfully.\n");

    return 0;
}

Each successful run adds another line to the end of the file.

7. Character-Based File Functions

fputc()

Writes one character to a file. 

fputc('A', fp);

fgetc()

Reads one character from a file. 

int ch = fgetc(fp);

if (ch != EOF)
{
    printf("%c", ch);
}
Use an int variable for the result of fgetc(), so it can represent every possible unsigned-character value as well as EOF.

8. Closing a File: fclose()

Always close a file when you have finished using it. The fclose() function releases resources associated with the open file. 

fclose(fp);

Closing a file also helps ensure that buffered output is properly handled.

9. Complete Example: Save and Read a Number

This program writes a number to a file, closes it, opens the file again, and reads the number back. 

#include <stdio.h>

int main(void)
{
    FILE *fp;
    int number;

    fp = fopen("number.txt", "w");

    if (fp == NULL)
    {
        printf("Unable to create file.\n");
        return 1;
    }

    fprintf(fp, "%d", 250);
    fclose(fp);

    fp = fopen("number.txt", "r");

    if (fp == NULL)
    {
        printf("Unable to read file.\n");
        return 1;
    }

    if (fscanf(fp, "%d", &number) == 1)
    {
        printf("Number from file: %d\n", number);
    }
    else
    {
        printf("Could not read a valid number.\n");
    }

    fclose(fp);

    return 0;
}

Expected Output

Number from file: 250

The program creates number.txt, saves 250, and then reads it back.

10. Common Mistakes

  • Not checking whether fopen() returned NULL.
  • Using read mode when the file does not exist.
  • Accidentally erasing data by opening a file in "w" mode.
  • Forgetting to close a file.
  • Using a file pointer after its file has been closed.
  • Assuming the file is saved in the same directory as the source code without checking the working directory.
