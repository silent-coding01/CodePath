Preprocessor Directives in C

Learn how the C preprocessor handles header files, macros, and conditional compilation before the compiler translates your program.

Learning goal: Understand the most common preprocessor directives.

1. What Is the C Preprocessor?

The preprocessor performs certain operations on your source code before the main compilation process.

Preprocessor directives begin with the # symbol.

#include <stdio.h>
#define MAX 100

These are directives, not ordinary C statements. They do not normally end with a semicolon.

Remember the general order: preprocessing, compilation, assembly, and linking. Toolchains may combine some stages.

2. The #include Directive

The #include directive makes a header file's contents available to your source file through preprocessing.

Angle brackets

#include <stdio.h>

Commonly used for standard library headers such as stdio.h and string.h.

Double quotation marks

#include "myheader.h"

Commonly used for your own header files. The exact file-search rules depend on the compiler.

3. The #define Directive

Use #define to create a macro. An object-like macro replaces occurrences of its name with replacement text. 

#include <stdio.h>
#define PI 3.14159

int main(void)
{
    float radius = 5.0f;
    float area = PI * radius * radius;

    printf("Area = %.2f\n", area);

    return 0;
}

Output:

Area = 78.54

The preprocessor replaces PI with 3.14159 before compilation.

Unlike a variable declaration, #define PI 3.14159 does not create a typed variable.

4. Function-Like Macros

A function-like macro can accept arguments. Parentheses are important when defining expressions. 

#include <stdio.h>
#define SQUARE(x) ((x) * (x))

int main(void)
{
    printf("%d\n", SQUARE(5));

    return 0;
}

Output:

25

The parentheses help prevent common operator-precedence errors.

Macro arguments may be evaluated more than once. Avoid calls such as SQUARE(i++). For many tasks, a function is safer and easier to debug.

5. The #undef Directive

The #undef directive removes an existing macro definition. 

#define VALUE 10
#undef VALUE

/* VALUE is no longer defined as a macro here. */

After #undef VALUE, the preprocessor no longer substitutes the previous definition of VALUE.

6. Conditional Compilation

Conditional directives control whether portions of source code are included in the compilation.

Using #ifdef

#include <stdio.h>
#define DEBUG

int main(void)
{
#ifdef DEBUG
    printf("Debug mode is active.\n");
#endif

    printf("Program running.\n");

    return 0;
}

Output:

Debug mode is active.
Program running.

Other useful directives

  • #ifndef — includes code when a macro is not defined.
  • #if — tests a preprocessor constant expression.
  • #elif — tests another condition.
  • #else — selects the alternative branch.
  • #endif — ends the conditional section.

7. Header Guards

Header guards prevent the same header file from being processed repeatedly within one translation unit. 

#ifndef MYHEADER_H
#define MYHEADER_H

void greet(void);

#endif

If MYHEADER_H has already been defined, the declarations inside the guarded section are skipped.

8. Common Mistakes

  • Adding a semicolon to the end of a simple #define replacement when it should not be there.
  • Forgetting parentheses in function-like macros.
  • Assuming macros behave exactly like functions.
  • Forgetting to close a conditional section with #endif.
  • Using a macro when a normal function would be clearer and safer.

10. Coding Challenges

Easy: Constant Macro

Define a macro named AGE with the value 20. Print the value using printf().

Medium: Maximum Macro

Create a macro named MAXIMUM(a, b) that returns the larger of two values. Test it with two integers.

Hard: Debug Mode

Use #define DEBUG and #ifdef DEBUG to print a debug message only when debug mode is enabled.
