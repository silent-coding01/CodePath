Chapter 5: Loops in C

Learn how to repeat instructions efficiently using loops.

1. What Is a Loop?

A loop repeats a block of code while a condition is satisfied or for a specified number of repetitions. Loops help avoid writing the same statements repeatedly.

#include <stdio.h> int main(void) { int i; for (i = 1; i <= 3; i++) { printf("Hello\n"); } return 0; }

Output:

Hello Hello Hello

2. The for Loop

A for loop is commonly used when the number of repetitions is known.

for (initialization; condition; update) { // Repeated statements }

Example: Print numbers from 1 to 5.

int i; for (i = 1; i <= 5; i++) { printf("%d ", i); }

Output: 1 2 3 4 5

Initialization runs once. The condition is checked before each iteration. The update runs after each iteration.

3. The while Loop

A while loop checks its condition before executing the loop body. If the condition is false initially, the body does not execute.

int i = 1; while (i <= 5) { printf("%d ", i); i++; }

Output: 1 2 3 4 5

Remember to update the loop variable when necessary. Otherwise, the loop may run indefinitely.

4. The do-while Loop

A do-while loop checks its condition after executing the body. Therefore, its body executes at least once.

int i = 1; do { printf("%d ", i); i++; } while (i <= 5);

Output: 1 2 3 4 5

Notice the semicolon after the condition: while (i <= 5);

5. Difference Between the Three Loops

  • for: Useful when repetitions are controlled by initialization, condition, and update.
  • while: Checks the condition before every iteration.
  • do-while: Executes the body before checking the condition.

6. The break Statement

The break statement immediately exits the nearest enclosing loop.

int i; for (i = 1; i <= 10; i++) { if (i == 5) { break; } printf("%d ", i); }

Output: 1 2 3 4

7. The continue Statement

The continue statement skips the remaining statements in the current iteration and proceeds to the next iteration.

int i; for (i = 1; i <= 5; i++) { if (i == 3) { continue; } printf("%d ", i); }

Output: 1 2 4 5

8. Nested Loops

A nested loop is a loop placed inside another loop. Nested loops are useful for patterns, tables, and two-dimensional arrays.

int i, j; for (i = 1; i <= 3; i++) { for (j = 1; j <= 3; j++) { printf("* "); } printf("\n"); }

Output:

* * * * * * * * *

The inner loop completes all its iterations for each iteration of the outer loop.

9. Common Loop Mistakes

  • Forgetting to update the loop variable when an update is required.
  • Using the wrong condition, such as i < 5 instead of i <= 5.
  • Adding an unnecessary semicolon after a for or while header.
  • Confusing break with continue.
  • Incorrectly tracing nested loops.
