Structures and Unions in C

Learn how to group related data using structures and how unions allow multiple members to share the same memory.

Learning goals: Understand structures, structure variables, arrays of structures, nested structures, pointers to structures, and unions.

1. What Is a Structure?

A structure is a user-defined data type that groups variables of different data types under one name.

For example, a student has a name, roll number, and marks. These values have different data types but belong to the same student. 

struct Student
{
    int roll;
    char name[30];
    float marks;
};

Here:

  • struct is the structure keyword.
  • Student is the structure tag.
  • roll, name, and marks are members.
The structure definition describes the format of the data. It does not, by itself, create a structure variable.

2. Declaring Structure Variables

You can declare variables after defining the structure.

#include <stdio.h>

struct Student
{
    int roll;
    float marks;
};

int main(void)
{
    struct Student s1;

    s1.roll = 101;
    s1.marks = 85.5f;

    printf("Roll: %d\n", s1.roll);
    printf("Marks: %.2f\n", s1.marks);

    return 0;
}

Output:

Roll: 101
Marks: 85.50

The dot operator (.) accesses a member of a structure variable.

3. Initializing a Structure

You can initialize structure members when declaring a variable. 

#include <stdio.h>

struct Student
{
    int roll;
    float marks;
};

int main(void)
{
    struct Student s1 = {101, 92.5f};

    printf("%d\n", s1.roll);
    printf("%.1f\n", s1.marks);

    return 0;
}

Output:

101
92.5

Values in a positional initializer correspond to the structure members in declaration order.

4. Taking Input into a Structure

#include <stdio.h>

struct Student
{
    int roll;
    char name[30];
    float marks;
};

int main(void)
{
    struct Student s1;

    printf("Enter roll number: ");
    scanf("%d", &s1.roll);

    printf("Enter name: ");
    scanf("%29s", s1.name);

    printf("Enter marks: ");
    scanf("%f", &s1.marks);

    printf("\nStudent Details\n");
    printf("Roll: %d\n", s1.roll);
    printf("Name: %s\n", s1.name);
    printf("Marks: %.2f\n", s1.marks);

    return 0;
}

Notice that & is used for the integer and float members in scanf(), but not for the character array s1.name.

This example reads a single-word name. To accept spaces in a name, use a suitable line-input method such as fgets().

5. Array of Structures

An array of structures stores multiple records of the same structure type. 

#include <stdio.h>

struct Student
{
    int roll;
    float marks;
};

int main(void)
{
    struct Student s[3] = {
        {1, 80.5f},
        {2, 91.0f},
        {3, 76.5f}
    };

    int i;

    for (i = 0; i < 3; i++)
    {
        printf("Roll: %d, Marks: %.1f\n",
               s[i].roll, s[i].marks);
    }

    return 0;
}

Output:

Roll: 1, Marks: 80.5
Roll: 2, Marks: 91.0
Roll: 3, Marks: 76.5

6. Nested Structures

A nested structure is a structure that contains another structure as one of its members. 

#include <stdio.h>

struct Date
{
    int day;
    int month;
    int year;
};

struct Student
{
    int roll;
    struct Date birth;
};

int main(void)
{
    struct Student s1 = {101, {15, 8, 2006}};

    printf("Roll: %d\n", s1.roll);

    printf("Date of birth: %02d-%02d-%d\n",
           s1.birth.day,
           s1.birth.month,
           s1.birth.year);

    return 0;
}

Output:

Roll: 101
Date of birth: 15-08-2006

Use multiple dot operators to access nested members, such as s1.birth.day.

7. Pointers to Structures

A pointer can store the address of a structure variable. The arrow operator (->) accesses members through a structure pointer. 

#include <stdio.h>

struct Student
{
    int roll;
    float marks;
};

int main(void)
{
    struct Student s1 = {101, 88.5f};
    struct Student *ptr = &s1;

    printf("Roll: %d\n", ptr->roll);
    printf("Marks: %.1f\n", ptr->marks);

    return 0;
}

Output:

Roll: 101
Marks: 88.5
ptr->roll is equivalent to (*ptr).roll.

8. Structure vs Array

  • An array stores multiple elements of the same type.
  • A structure groups members that can have different types.
int numbers[3] = {10, 20, 30};

struct Student
{
    int roll;
    float marks;
    char grade;
};

Use arrays for collections of similar values and structures for records containing related fields.

9. What Is a Union?

A union is a user-defined data type in which all members share the same memory region. 

union Data
{
    int number;
    float decimal;
    char letter;
};

Unlike a structure, a union does not provide separate storage for every member. Its members overlap in memory.

A union can contain several members, but that does not mean all members can hold independent values at the same time.

10. Using a Union

#include <stdio.h>

union Data
{
    int number;
    float decimal;
    char letter;
};

int main(void)
{
    union Data d;

    d.number = 25;
    printf("Number: %d\n", d.number);

    d.decimal = 12.5f;
    printf("Decimal: %.1f\n", d.decimal);

    d.letter = 'A';
    printf("Letter: %c\n", d.letter);

    return 0;
}

Output:

Number: 25
Decimal: 12.5
Letter: A

Each value is assigned and read while that member is the one being used. Writing to another member changes the stored representation in the shared memory.

In ordinary code, read the member whose value was most recently stored, unless you specifically understand the rules for interpreting another member's representation.

11. Structure vs Union

struct Example
{
    int a;
    float b;
};

union Example
{
    int a;
    float b;
};

Main differences:

  • Structure: Each member has its own storage.
  • Union: All members share the same storage.
  • Structure: Members can hold independent values simultaneously.
  • Union: Writing one member affects the shared representation.
  • Size: A structure's size includes space for all members and any required padding. A union's size is sufficient for its largest member and any required alignment.
Remember: structures are useful for grouping related information; unions are useful when different data representations need to reuse the same memory.

12. Common Mistakes

  • Forgetting the semicolon after a structure or union definition.
  • Using . instead of -> when accessing a member through a pointer.
  • Forgetting that a structure variable must be declared before using it.
  • Assuming a union can safely preserve independent values in all its members.
  • Confusing a structure tag with a variable name.
