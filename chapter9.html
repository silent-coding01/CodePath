1. Introduction to Functions

A function is a named block of code that performs a particular task. A function can be called whenever its task is needed.

For example, we can create a function to print a greeting.

#include <stdio.h>

void greet(void)
{
    printf("Hello, Arman!\n");
}

int main(void)
{
    greet();
    greet();

    return 0;
}

Output:

Hello, Arman!
Hello, Arman!

The function greet() is defined once but called twice. Each call executes its body.

Remember: In C, execution normally starts from main(). The statements inside greet() run when the program calls greet().

2. Why Use Functions?

  • Reusability: Write code once and use it many times.
  • Organization: Divide a large program into smaller parts.
  • Readability: Give meaningful names to tasks.
  • Maintenance: Fix or improve one function without rewriting the entire program.
  • Testing: Test a small part of a program independently.
Instead of writing the same calculation several times, you can put it in a function and call that function whenever needed.

3. Declaration, Definition, and Function Call

A function commonly involves three important parts.

A. Function declaration (prototype)

int add(int a, int b);

This tells the compiler the function's name, return type, and parameter types before the function is called.

B. Function definition

int add(int a, int b)
{
    return a + b;
}

This contains the actual code that performs the task.

C. Function call

result = add(10, 20);

This calls the function and stores the returned value in `result`.

Complete program

#include <stdio.h>

int add(int a, int b);

int main(void)
{
    int result = add(10, 20);

    printf("Sum = %d\n", result);

    return 0;
}

int add(int a, int b)
{
    return a + b;
}

Output:

Sum = 30
A declaration is useful when the function definition appears after the function that calls it. A definition placed before the call can also make a separate prototype unnecessary.

4. No Arguments and No Return Value

A function with no parameters receives no arguments from its caller. A function with return type void does not return a value. 

#include <stdio.h>

void showMessage(void)
{
    printf("Welcome to CodePath!\n");
}

int main(void)
{
    showMessage();

    return 0;
}

Output:

Welcome to CodePath!

The first void means the function returns no value. The void inside the parentheses means it takes no parameters.

5. Functions with Arguments

A function can receive information through parameters. The values supplied in the function call are called arguments. 

#include <stdio.h>

void square(int n)
{
    printf("Square = %d\n", n * n);
}

int main(void)
{
    square(5);
    square(8);

    return 0;
}

Output:

Square = 25
Square = 64

Here, n is a parameter. The values 5 and 8 are arguments passed in separate calls.

6. Functions with Return Values

A function can calculate a result and return it to the caller using the return statement. 

#include <stdio.h>

int square(int n)
{
    return n * n;
}

int main(void)
{
    int result = square(6);

    printf("Square = %d\n", result);

    return 0;
}

Output:

Square = 36

The expression n * n is calculated inside square(). The resulting value is returned to main().

Important: A function declared with return type int should return an appropriate integer value on every path where its caller expects a result.

7. Arguments and Return Values

A function can accept arguments and return a result. This is a common way to perform calculations. 

#include <stdio.h>

int multiply(int a, int b)
{
    return a * b;
}

int main(void)
{
    int result;

    result = multiply(4, 7);

    printf("Product = %d\n", result);

    return 0;
}

Output:

Product = 28

The function receives two arguments, multiplies them, and returns the product.

8. Multiple Parameters

Functions can accept more than one parameter. The arguments must correspond to the parameter types and order. 

#include <stdio.h>

int maximum(int a, int b, int c)
{
    if (a >= b && a >= c)
        return a;
    else if (b >= a && b >= c)
        return b;
    else
        return c;
}

int main(void)
{
    int result = maximum(15, 42, 27);

    printf("Maximum = %d\n", result);

    return 0;
}

Output:

Maximum = 42
The three arguments 15, 42, and 27 are received by parameters a, b, and c, respectively.

9. Local and Global Variables

Local variable

A local variable declared inside a function or block is accessible within its scope. 

void example(void)
{
    int x = 10;
    printf("%d\n", x);
}

Global variable

A variable declared outside all functions has file scope. Functions in the same file can access it where its declaration is visible and no other scope rule prevents access. 

#include <stdio.h>

int total = 100;

void showTotal(void)
{
    printf("%d\n", total);
}

int main(void)
{
    showTotal();

    return 0;
}

Output:

100
Avoid using global variables unnecessarily. Passing data through function parameters often makes a program easier to understand and test.

10. Call by Value

In C, arguments are passed by value. A function receives its own parameter value, so changing that parameter does not directly change the caller's original variable. 

#include <stdio.h>

void change(int x)
{
    x = 100;
    printf("Inside function: %d\n", x);
}

int main(void)
{
    int number = 10;

    change(number);

    printf("Inside main: %d\n", number);

    return 0;
}

Output:

Inside function: 100
Inside main: 10

The parameter x receives a copy of number. Assigning 100 to x does not change number.

11. Common Mistakes

Mistake 1: Calling a function with the wrong arguments

int add(int a, int b)
{
    return a + b;
}

/* Correct call */
add(5, 7);

Supply arguments that match the function's parameter requirements.

Mistake 2: Forgetting a return value

If a function is supposed to return an integer result, make sure it returns an appropriate value on every expected path.

Mistake 3: Confusing printing and returning

void showSum(int a, int b)
{
    printf("%d\n", a + b);
}

This function prints a sum but does not return it. Use an int function with return if the caller needs to use the result in another calculation.

Mistake 4: Forgetting a declaration when needed

If a function is defined after a call to it, provide a compatible declaration before the call.

Mistake 5: Expecting call by value to change the original

Changing an ordinary parameter changes the parameter itself, not the caller's original variable.

13. Coding Challenges

Easy

  1. Write a function that prints a greeting.
  2. Write a function that accepts an integer and prints its square.
  3. Write a function that returns the sum of two integers.

Medium

  1. Write a function that returns the maximum of two numbers.
  2. Write a function that checks whether a number is even.
  3. Write a function that calculates the sum of digits of an integer.
  4. Write a function that checks whether a number is prime.

Hard

  1. Write a function that reverses an integer.
  2. Write a function that checks whether a number is a palindrome.
  3. Write a function that calculates the sum of the digits in a range of numbers.
  4. Write a calculator using separate functions for addition, subtraction, multiplication, and division.
Practice tip: First decide what input a function needs and what result it should produce. Then write its declaration, definition, and call.
